# Support

- **Questions and discussion:** [Discord](https://wilds.ai/discord). GitHub issues are for bugs and feature requests.
- **Documentation:** the [README](https://github.com/framerslab/paracosm/blob/master/README.md), the guides in [docs/](https://github.com/framerslab/paracosm/tree/master/docs) and the [API reference](https://paracosm.agentos.sh/docs)
- **Bugs and feature requests:** the [issue forms](https://github.com/framerslab/paracosm/issues/new/choose). Search the existing issues first. A bug in the AgentOS runtime belongs in [agentos](https://github.com/framerslab/agentos/issues/new/choose).
- **Security issues:** report privately as the [security policy](https://github.com/framerslab/paracosm/blob/master/.github/SECURITY.md) describes, never in a public issue.
- **Commercial, partnership or sponsorship inquiries:** team@frame.dev

To contribute, see [CONTRIBUTING.md](https://github.com/framerslab/paracosm/blob/master/CONTRIBUTING.md).
